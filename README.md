# Dayboard workspace

The AI-DLC workspace for **Dayboard**: a daily page made of blocks (open items,
meetings, pull requests, learnings, waiting on others) that a person and their
AI assistant keep together. This repository holds the design records, the
team's rules and knowledge, and the engine shell; the code lives in
[dayboard-api](https://github.com/maksymskuibida/dayboard-api) and
[dayboard-web](https://github.com/maksymskuibida/dayboard-web), checked out as
children of this directory.

## Layout

- `aidlc/spaces/dayboard/` is the space the team works in: `memory/` (the rules,
  still the shipped templates), `knowledge/`, `codekb/`, `intents/` (one record
  per piece of work).
- `aidlc/spaces/default/` is the engine's seed space, kept as the template.
- `.claude/` is the engine shell for Claude Code, generated by `aidlc config`
  for the release pinned in `.aidlc-version`. Never edited by hand.

## Set up a clone

```bash
git clone https://github.com/maksymskuibida/dayboard-workspace.git
cd dayboard-workspace
git clone https://github.com/maksymskuibida/dayboard-api.git
git clone https://github.com/maksymskuibida/dayboard-web.git
aidlc config --pin "$(cat .aidlc-version)" --yes   # registers this clone with the pinned release
aidlc engine space switch dayboard                  # the space the team works in; the cursor is per clone
```

A git worktree is its own clone for this purpose: switch the space there too.

Then open Claude Code here and run `/aidlc --doctor`.

## Rules

There are none yet. The way of working, the testing posture and the project
rules are decided in Ideation and Inception of the first piece of work, as the
workflow intends, and land here through pull requests.
